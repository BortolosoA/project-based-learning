# Exercício 7 — Laço for

## Conceito
Repetição com `for`.

## Enunciado
Crie um arquivo `Tabuada.java` que:
1. Leia um número inteiro do usuário.
2. Imprima a tabuada desse número de 1 a 10 usando `for`.

## Exemplo
```
Digite um número: 7
7 x 1 = 7
7 x 2 = 14
...
7 x 10 = 70
```

## Extra (opcional)
Imprima também a soma de todos os resultados da tabuada.

## Como executar
```bash
javac Tabuada.java
java Tabuada
```
