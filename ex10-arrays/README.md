# Exercício 10 — Arrays

## Conceito
Declaração, preenchimento e percorrimento de arrays.

## Enunciado
Crie um arquivo `Notas.java` que:
1. Peça ao usuário quantas notas deseja informar.
2. Crie um array de `double` com esse tamanho e leia todas as notas.
3. Calcule e imprima:
   - A média das notas;
   - A maior nota;
   - A menor nota.

## Exemplo
```
Quantas notas? 3
Nota 1: 7.5
Nota 2: 4.0
Nota 3: 9.0
Média: 6.833333333333333
Maior: 9.0
Menor: 4.0
```

## Como executar
```bash
javac Notas.java
java Notas
```
